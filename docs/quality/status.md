# 品質ステータス

最終更新: 2026-06-23

## ドメイン別グレーディング

| ドメイン | グレード | カバレッジ | 備考 |
|----------|----------|------------|------|
| 性格診断 | A | テスト済み・DB保存済み | BIG5計算、タイプ判定、XState制御、診断結果保存・履歴作成まで実装・テスト済み |
| マッチング | B | 主要フロー実装済み | おすすめ案件、応募、応募状況、承認/辞退、活動完了、マッチング履歴、双方向アプローチ、LINE連絡先開示をDB接続済み |
| 認証 | B | OAuth/ロール制御実装済み | Google OAuth UI、callback、m_user同期、ロール選択、保護ルート、凍結ユーザーのサインアウト導線を実装済み |
| UI/UX | B | MVP主要画面実装済み | 参加者、団体、管理者、証明書、アプローチ関連画面に加え、主要ルートのloading/error共通表示を実装済み。総合E2Eと本番手動確認は未完了 |
| API | B | Server Actions中心に実装済み | Auth callback、診断、オンボーディング、案件、応募、管理、アプローチ、証明書のServer Actions/Route Handlerをテスト付きで実装済み |
| DB | B | Prisma schema/migration実装済み | ユーザー、プロフィール、案件、応募、団体審査、アプローチ、証明書、凍結監査のモデルとmigrationを実装済み |
| 管理機能 | B | 主要管理画面実装済み | 団体審査、審査履歴、ユーザー一覧、アカウント凍結/解除を実装済み |
| インフラ | D | Docker開発環境中心 | Vercel/本番環境の実動作確認は別途必要 |

## グレード定義

- **A** — 実装完了、テスト済み、本番品質
- **B** — 実装完了、部分的テスト or 限定スコープ
- **C** — 実装途中、基本動作はする
- **D** — 最小限の実装、開発支援レベル
- **F** — 未着手 or 設計のみ
