# トップページ（認証なし）デザイン設計書

## 概要

認証不要のランディングページ（`/` ルート）を作成する。Figmaデザイン（node-id: 1-190）に忠実に実装。

## デザイン元

Figma: `https://www.figma.com/design/FvrJszRpTTM2mEwrnbdrDj/ボランティ-MCP接続用?node-id=1-190`

## ページ構成

### 1. ヘッダー
- ロゴアイコン（Heart） + 「ボランティアマッチング」
- サブテキスト「あなたにぴったりの活動を見つけよう」
- 右側: 「ログイン」ボタン（アウトライン） + 「新規登録」ボタン（オレンジ塗り）
- 背景: rgba(255,238,226,0.6)、下ボーダー

### 2. ヒーローセクション
- ハート + スパークルアイコン
- 大見出し「あなたにぴったりの**ボランティア活動**を見つけよう」
- 副文「簡単な診断を通じて、あなたの特性に最も適したボランティア活動をご提案します」
- CTA 2つ:
  - 「16問 簡易診断 約2分」（アウトライン）
  - 「60問 詳細診断 約8〜10分 →」（オレンジ塗り）
- 補足テキスト

### 3. 特徴カード（3列）
| カード | アイコン | タイトル         | 説明                                    |
| ------ | -------- | ---------------- | --------------------------------------- |
| 1      | Target   | 正確なマッチング | 16問の簡易診断や60問の詳細診断により... |
| 2      | Users    | 多様な活動       | 教育支援、環境保護、災害支援...         |
| 3      | Heart    | 社会貢献         | あなたの特技や関心を活かして...         |

### 4. 診断の種類（2列比較）
| 簡易診断                         | 詳細診断                   |
| -------------------------------- | -------------------------- |
| 16問 / 約2分                     | 60問 / 約8〜10分           |
| サクッとボランティアタイプを診断 | より精密な性格分析         |
| 基本的な特性と傾向を分析         | 12の特性を多角的に分析     |
| 初めての方におすすめ             | より適切なマッチングを実現 |

### 5. 利用の流れ（3ステップ）
1. ボランティア診断 — 10問または96問の質問に答えて診断
2. マッチング — 診断結果に基づいて最適な活動を提案
3. 参加申し込み — 気になる活動があれば詳細確認して申し込み

lucide-react を使用:

## 技術仕様

- **ファイル:** `app/src/app/page.tsx`（書き換え）、`app/src/app/layout.tsx`（フォント追加）
- **コンポーネント:** Server Component（`"use client"` 不要）
- **スタイリング:** Tailwind CSS 4
- **レスポンシブ:** モバイルファースト、md: / lg: でブレークポイント対応
- **追加パッケージ:** なし（全て既存で対応）
