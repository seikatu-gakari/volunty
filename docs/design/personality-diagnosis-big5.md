# 性格診断アルゴリズム設計書（BIG5版）【廃止】

> **この設計書は 2026-07 の診断・マッチング基盤再設計により廃止されました。**
> 現行の設計は [personality-matching-redesign.md](./personality-matching-redesign.md) を参照してください。

## 廃止された内容（概要）

本書が規定していた以下の方式は、すべて撤去済みです。

- 出典のない独自60問と、独自の簡易16問/詳細60問の2モード
  → **IPIP Lexical Big-Five Factor Markers 日本語版（public domain）** に置換。
  現行も簡易15問/全50問の2モードを提供するが、簡易版はIPIP-BFM-50-JAの項目をそのまま
  抜粋したもの（scaleCode分離）であり、旧・独自の簡易16問とは別物
- 単純平均の0〜100正規化を母集団内の位置のように表示する構成
  → raw score（項目合計）を正とし、0〜100は「回答の換算値」と明示。percentile・T得点は標準化データが得られるまで非表示
- 10人物タイプの固定閾値判定（完全一致・priority・ユークリッド距離フォールバック）
  → 連続スコアを主結果とし、タイプは「活動スタイルの参考情報」に再定義
- 診断スコアと案件 `requirement_traits` のユークリッド距離によるマッチング
  → 診断とマッチングを分離。ハード条件とルールベースランキング（興味・地域・日程・参加形態・活動スタイルタグへの加点・新着性）に置換
- AWS Bedrock による診断解説生成・BIG5特徴量の協調フィルタリング・重み40/40/20のハイブリッド統合（未実装の構想）
  → 学習モデルは前提条件を満たすまで実装しない。イベント収集（推薦ログ・閲覧・応募・評価）と評価指標の定義までを実装
