# 活動スタイル v2（Issue #307）

## 目的と範囲

実測の5特性を主役にし、説明の補助として5軸×両方向の対称な10方向を用いる。心理学的に検証された類型、能力・適性評価、母集団内順位ではない。採点・設問・逆転項目・尺度版・回答品質判定・推薦計算は変更しない。低協調性から批判的思考力、低情緒安定性から共感力や芸術性を推測しない。

## 決定規則（2.0.0）

軸順は E 外向性、A 協調性、C 誠実性、S 情緒安定性、I 知性・想像性。Sを神経症傾向と取り違えない。アンカーは対象軸75または25、他軸50。対称アンカーへのユークリッド距離の比較は、中心50からの符号付き偏差の比較と同値だが、単一勝者を強制しない。

1. 全軸の最大絶対偏差が15未満なら中立
2. それ以外は最大絶対偏差との差が10未満の方向をすべて残す
3. 1方向は単独、2〜5方向は混合。軸順は表示順だけに使う

15と10は強い根拠のない差を過剰解釈しないための**暫定UX定数**。統計的・臨床的な境界でも測定誤差の推定値でもない。低偏差全体では方向を選ばず、強い方向がある場合も近接した別方向を隠さない。最大偏差15は中立でなく、差10は混合候補に含めない。コードとテストで境界を固定し、変更時は分類版と保存ID名前空間を更新する。

### 境界感度

全50問は各軸10項目で1段階回答差が2.5点、簡易15問は各軸3項目で約8.33点（表示は小数1桁）となる。全50問62.5→65、簡易58.3→66.7で中立／単独が変わりうる。75と65は差10のため単独、75と65.1は混合になる。これは分類の便宜であって意味の急変ではない。全50問でも境界は不安定で、簡易版はより粗い。回答品質フラグは独立して表示し、方向へ変換しない。

検証は全50点、全10アンカー、2〜5方向同点、境界周辺、不正値を含む。5値の5軸直積3125組で各方向の登場数が等しいことを確認するのは**アルゴリズムの対称性**だけであり、実人口の比率ではない。実集団で均等出現するよう調整しない。採用閾値の利用者調査・心理測定的検証は未実施。

## 保存と互換性

既存DBの `style_type_version = 2.0.0`、`style_type_id` に `v2:neutral` または `v2:e-high,a-low,c-high,s-low,i-high` のような正規順IDを保存する。軸コードとhigh/lowの全方向を保持し、最大37文字以下で既存varchar(50)内。中立や混合をnullや代表1方向へ縮退させない。実測raw/scaledScoresは別欄へそのまま保存し、アンカーへ置換しない。schema migrationは不要。

旧1.0.0および既存修復migration由来のlegacy版の定義・ID・動物対応を維持。取得は保存IDを解決するだけで過去結果をスコアから再分類しない。本診断・一覧・団体画面・マイページの取得は保存版も伝搬し検査する。既存一覧・マイページ・団体画面は同じID resolverを経由し、v2名前空間を正規化済み方向表示へ復元する。ID名前空間自体が規則版を識別するため、一覧に余分なスコア開示を追加しない。未知IDや不整合版は分類表示なしとし、実測スコアを維持。

推薦エンジン・活動タグは実測scaledScoresを利用し、分類ID・アンカーを使わないため変更しない。外部連携がstyle_type_idを固定10値と仮定している場合は新しい複合IDに対応が必要（本リポジトリの呼出元は監査済み）。

## PR #306の動物との統合

2026-10-05の確認時点で #306 はmainへマージ済み。画像と旧ID対応を維持し旧結果で表示する。新分類は方向を正確に伝える文字UIを使用し、既存動物の名前やキャッチコピーを別の意味へ流用しない。

後続で新10方向ごとの動物・名前・説明の対応表を承認してから、v2専用の表示マッピングを追加する。中立に特定動物を強制しない。混合は全方向を同列に扱い代表動物を勝手に選ばない。画像再生成や追加は今回の対象外。

## 検証・運用

UTは分類、正規ID、保存・再読込（50問／15問）、旧結果と未知版、品質フラグを検証。UI/E2Eは本診断とお試し・再回答・狭幅を検証。DB統合E2EはCIの使い捨てSupabaseのみ。本番接続・保存済みレコード更新・mainマージは行わない。
