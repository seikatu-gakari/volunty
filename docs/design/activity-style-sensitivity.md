# 活動スタイル v2 の数値感度確認

## 結論と位置づけ

活動スタイル `2.0.0` の中立閾値15・混合差10を、**暫定のUX設定として維持する**。これは最適値の推定、心理測定的妥当性の確認、臨床的カットオフ、母集団内の頻度や順位の推定ではない。実スコアを説明する補助表示として、中心付近で単独方向を断定せず、近接方向を省略しない方針との整合を確認した。

- 50問版では1回答の1段階変更は2.5点、15問版では丸め後8.3または8.4点になる。短縮版のスタイルは特に境界変化が大きく、「安定した性格タイプ」と扱えない。
- 15/10でのID変化率は50問の3分布で7.97〜11.90%、15問で23.10〜48.69%。同じ閾値でも分布と尺度に依存する。これは後述の人工的な回答配置における変化率であり、利用者の再検査信頼性ではない。
- 対称拡張で10方向の出現数は完全一致し、各回答の軸移動・符号反転に対する対応も一致する。一方、偏った元データの出現数は均等にならない。均等な分類頻度を目標に閾値を最適化しない。
- 中立、単独、混合2〜5方向は、両尺度とも実際に採点可能な回答から到達する。合成分布の有限サンプルに混合5等が出ない場合は、到達不能という意味ではない。
- 中立15/混合10の根拠は表示上の慎重さと複数候補の保持であり、統計的優位性ではない。実回答に適した校正には、目的・対象を明示し適切な同意を得たデータで、回答分布、再回答時の変化、表示理解、尺度別の差などを別途検討する必要がある。リポジトリにはその根拠がない。この将来課題は今回の実装完了を妨げる未実装事項ではない。

## 対象コードと再現方法

- 採点: `app/src/lib/diagnosis-scale/scoring.ts` の `scoreDiagnosis`
- 尺度: `app/src/lib/diagnosis-scale/scale.ts` の50問版と15問抜粋版
- 製品分類: `app/src/lib/diagnosis-scale/activity-styles.ts`
- 再現テスト: `app/src/lib/diagnosis-scale/activity-style-sensitivity.test.ts`

```sh
cd app
ACTIVITY_STYLE_SENSITIVITY_REPORT=1 npm test -- src/lib/diagnosis-scale/activity-style-sensitivity.test.ts
```

テストはDB、外部通信、実利用者データ、現在時刻を使わない。以下の表はこのコマンドの `SENSITIVITY_REPORT_BEGIN` と `SENSITIVITY_REPORT_END` の間から取得した。比較表と対称性集計全体のSHA-256をインラインスナップショットとして固定し、変更時に再検討できる。スナップショット更新だけで正当化せず、変更理由と本書の表も確認する。

## 手順と限界

### 採点粒度と境界

項目数を各軸 `n` とすると、逆転処理後の合計 `raw` を `(raw-n)/(4n)*100` へ線形変換し、小数1桁に丸める。50問は各軸10項目、15問は各軸3項目。全到達可能な合計を実回答へ変換して採点し、41段階（2.5点刻み）と13段階（8.3/8.4点刻み）を確認する。全近傍についても「変更軸は1つだけ・変化量はこの刻み」という条件を確認する。

製品の境界は厳密な不等号である。

- 全軸の中心50からの最大距離が **15未満** なら中立。15は単独または混合側
- 中立以外は、最大距離との差が **10未満** の非ゼロ方向をすべて保持。差10は含まない
- 50問では中心から12.5→15の1変更で中立境界を越える。15問では8.3→16.7で越える
- 15問の中心距離は0、8.3、16.7、25、33.3、41.7、50。したがって中立閾値10と15は同じ集合を中立にする。方向間距離差に10以上15未満の値がないため、混合差10と15も同じ結果になる。これはサンプルの偶然ではなく、採点格子の性質
- 混合候補は中心から15以上の方向に限定しない。中立判定を通った後は「最大距離との差」で選ぶ。たとえば最大距離16.7なら距離8.3も混合差10内に入る

### 合成分布

各尺度・各分布につき256基準回答、合計1,536回答。32ビットLCGを用い、初期値は `3082026 + 問数 + 分布番号`（center=0、uniform=1、skewed=2）。更新式は `(1664525 * state + 1013904223) mod 2^32`、出力は `state / 2^32`。コードでは `Math.imul` と符号なし変換を使う。

| 分布 | 合計点の生成 | 意図 |
| --- | --- | --- |
| center | 各軸でn回、1/2/3/4/5を確率0.05/0.20/0.50/0.20/0.05で抽出して合計 | 中心付近が多い場合。15問は平均化が弱い |
| uniform | 各軸の到達可能な合計n〜5nの整数を一様抽出 | 広い得点域。各設問の独立一様回答とは異なる |
| skewed | 各軸で4n回のベルヌーイ試行の成功数+n。軸順の成功確率は0.80/0.65/0.45/0.30/0.20 | 軸・符号の頻度が異なる非対称な場合 |

合計点は各軸の項目にできるだけ均等に配分し、実際の逆転キーに応じて回答値へ戻す。この人工的配置を採る理由は、全ての合計点から有効な完全回答を決定的に作るため。元の項目抽出列の保持や、実回答者の項目間相関の再現はしていない。基準回答の採点は全件 `scoreDiagnosis` に通す。

各基準回答について、各項目を1つだけ±1した、値1〜5に収まる全変更を採点する。端点1の−1、5の+1は除外する。同じスコアになる別項目の変更も別の変更として数えるため、割合は**有効な回答変更イベントで重みづけた割合**。基準回答ごとの割合の平均や、ユニークなスコアの割合ではない。均等配分した人工的配置に依存するため、この値を実人口に外挿しない。

9設定（中立10/15/20 × 混合差5/10/15）で同じ基準・近傍を比較する。製品設定15/10では、全基準・全近傍を製品関数と独立比較モデルの両方に渡してIDの一致を確認する。比較モデルは本番設定を書き換えない。

- 「ID変化」: 中立化、単独・混合の変更、混合内の候補増減や方向変更を含め、正規IDが変わった回数
- 「種別変化」: 中立／単独／混合の3区分が変わった回数。混合2→混合3等は含めない
- 表の中立〜混合5は基準回答の個数で、各行の合計256
- 軸・符号対称性は、元の各基準スコアを5通りに循環移動し、それぞれ原符号と全軸反転を含む10件へ拡張して検査。各条件2,560件での集計。入力分布を対称にした別検査であり、非対称分布の元データを置換して頻度を報告するものではない

## 閾値のトレードオフ

1. 中立域を広げると方向表示が減る。50問centerでは中立数が閾値10で77、15で196、20で245（各256件）。20なら安定に見えるが、ほぼ全件を中立にするため変化率が下がる側面がある。小さい変化率だけで20を選ばない。
2. 混合差を広げると単独が減り、候補数が増える。50問uniform・中立15では混合差5/10/15の単独が165/85/45。差5は近接を単独と扱いやすく、15は多方向表示が多くなる。10は近接方向を残しながら候補を無制限に広げない暫定値。
3. ID変化率は混合差に対して単調ではない。50問uniform・中立15で7.85→9.27→6.58%。閾値をどの境界に置くか、元分布がどこにあるかに左右される。一方で混合内の変化も含むID変化率と3種別変化率は異なるので、両方を示した。
4. 15問centerではID変化48.69%だが種別変化16.69%。近接候補の出入りが多い。候補集合を固定的な人格ラベルとして保存・説明したり、能力・適性の保証へ転用しない。表示は実スコアと短縮版の注意書きを伴わせる。
5. 全ての分布で頻度を均等にする基準は置かない。非対称分布で10方向の頻度が異なるのは入力による期待される挙動。将来の実データで閾値を変更する場合は、保存済み結果を再分類せず、分類版も更新する既存方針に従う。

## 検証範囲

追加内容は決定的なUTと本書だけで、製品の採点・閾値・画面操作は変更していない。この変更単独では新たなE2Eは不要。対象UTと既存の活動スタイルUTの計35テストが成功し、追加テストファイルのESLintも成功した。PR全体の画面・保存・推薦経路については、それぞれの変更に対応する検証を別途行う。
