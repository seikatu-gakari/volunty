# MVP計画

## 1. MVPの目的とスコープ

### 1.1 MVPのゴール
- ✅ 性格診断がボランティアマッチングの動機付けとして機能するか
- ✅ 参加者が診断結果をきっかけに団体へ応募するか
- ✅ 団体が「相性スコア付き応募」に価値を感じるか

### 1.2 MVPで **やること / やらないこと**

| やること（Phase 1）                                    | やらないこと（Phase 2以降）  |
| ------------------------------------------------------ | ---------------------------- |
| BIG5性格診断（50問）                                   | キャラクター画像生成         |
| 診断結果表示（10類型 + スコア）                        | SNSシェア機能                |
| OAuth認証（Google）                                    | LINE Messaging API連携       |
| 参加者プロフィール登録                                 | AI解説生成（Bedrock）        |
| 団体プロフィール・募集登録                             | 協調フィルタリング           |
| Big5ルールベースマッチング(アルゴリズムでのマッチング) | 東京アプリ連携               |
| 応募・承認フロー                                       | フィードバック・分析レポート |
| 双方向アプローチ機能                                   | 多言語対応                   |
| LINE ID表示（マッチ成立後）                            | レビュー機能(参加者、団体)   |
| 参加証明書発行機能（PDF/画像）                         |                              |
| 最低限の管理機能                                       |                              |

## 2. 機能洗い出し

### 2.1 参加者向け機能

| #    | 機能名                   | 説明                                                                 |
| ---- | ------------------------ | -------------------------------------------------------------------- |
| P-1  | OAuth ログイン           | Googleでソーシャルログイン                                           |
| P-2  | プロフィール登録         | 自己紹介、興味分野、活動可能日時、希望地域の登録                     |
| P-3  | 性格診断（50問）         | BIG5ベースの質問に1問ずつ回答。戻るボタン・進捗バー付き              |

| P-6  | 団体詳細閲覧             | 案件詳細から遷移。団体の活動内容、他の募集案件、相性スコアの詳細表示 |
| P-7  | 募集案件への応募         | 「応募する」ボタンで応募。簡単なメッセージを添付可能                 |
| P-8  | 応募状況確認             | 自分の応募一覧と各ステータス（応募中 / 承認 / 辞退）の確認           |
| P-9  | 団体からのアプローチ受信 | 団体からのスカウトメッセージ受信・確認                               |
| P-10 | アプローチへの返信       | 団体からのアプローチに対して承諾 or 辞退                             |
| P-11 | マッチ成立後LINE表示     | 承認された場合、団体のLINE情報を表示                                 |
| P-12 | 参加証明書発行           | 完了した活動の参加証明書をPDF/画像で生成・ダウンロード               |
| P-13 | 参加証明書一覧           | 過去に発行した証明書の一覧表示と再ダウンロード                       |
| P-14 | 診断やり直し             | 再診断して結果を上書き                                               |

## 5. 画面遷移フロー

### 5.1 参加者のメインフロー

```
トップ → ログイン → ロール選択(参加者) → プロフィール登録
  → 性格診断(50問) → 診断結果表示
  → おすすめ案件一覧 → 募集案件詳細 → 応募
  → マイページで応募状況確認 → マッチ成立 → LINE情報表示
  → 活動参加 → 活動完了 → 参加証明書発行申請 → 証明書ダウンロード
  
  ※並行フロー：団体からアプローチ受信 → 内容確認 → 承諾/辞退
  ※案件詳細から団体詳細の閲覧も可能
```

### 5.2 団体のメインフロー

```
トップ → ログイン → ロール選択(団体) → 団体プロフィール登録
  → 審査申請 → 審査待ち → 審査承認 → ダッシュボード → 募集案件作成
  → 応募者一覧確認（スコア順） → 応募者詳細確認
  → 承認 or 辞退 → マッチ成立 → LINE情報相互開示
  → 活動実施 → 活動完了報告 → 証明書発行承認
  
  ※並行フロー：おすすめ参加者閲覧 → 参加者詳細 → アプローチ送信 → 返信待ち
```

## 6. MVPリリース判定基準

### 6.1 Must Have（リリースに必須）
- [ ] OAuth ログイン（Google）が動作する
- [ ] 参加者が性格診断（50問）を完了できる
- [ ] 診断結果（人物タイプ + BIG5スコア）が正しく表示される
- [ ] 団体が登録申請できる
- [ ] 管理者が団体登録を審査・承認/却下できる
- [ ] 団体が審査ステータスを確認できる
- [ ] 審査承認後に団体が募集案件を作成できる
- [ ] 参加者に相性スコア付きの案件一覧が表示される
- [ ] 参加者が募集案件に応募できる
- [ ] 団体が応募を承認 / 辞退できる
- [ ] 団体が相性スコア順におすすめ参加者を閲覧できる
- [ ] 団体が参加者にアプローチメッセージを送信できる
- [ ] 参加者がアプローチを受信・承諾/辞退できる
- [ ] マッチ成立後にLINE情報が表示される
- [ ] 活動完了後に参加証明書を発行できる
- [ ] 団体が証明書発行リクエストを承認できる
- [ ] 参加者が証明書をダウンロード・印刷できる
- [ ] カテゴリ・地域によるフィルタリング
- [ ] 応募時のメッセージ添付
- [ ] レスポンシブ対応（モバイル最適化）

### 6.2 Nice to Have（あれば嬉しい）
- [ ] 診断やり直し機能
- [ ] 管理画面（ユーザー一覧・凍結）
- [ ] マッチング履歴一覧
