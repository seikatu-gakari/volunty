# NPO法人ヒアリングシート

## ヒアリング概要

| 項目       | 内容                                                                                                              |
| ---------- | ----------------------------------------------------------------------------------------------------------------- |
| 目的       | ボランティア団体と参加者をつなぐマッチングプラットフォーム（Volunty）の開発にあたり、現場の課題・ニーズを把握する |
| 対象       | ボランティアを募集しているNPO法人の担当者                                                                         |
| 所要時間   | 約45〜60分                                                                                                        |
| 実施日     | 年　　月　　日                                                                                                    |
| 団体名     |                                                                                                                   |
| 回答者名   |                                                                                                                   |
| 回答者役職 |                                                                                                                   |

> **ヒアリング時の注意事項**
> - 回答を誘導しない。オープンクエスチョンで深掘りする
> - 「なぜそう思うか」「具体的なエピソード」を引き出す
> - 自社サービスの説明は質問が終わってから行う（先入観を与えない）
> - 許可を得た上でメモ・録音を行う

## 質問項目

### 【前半：現状把握】（Q1〜Q7）サービス説明前に、バイアスなく現場の実態を聞き出す

---

### Q1. まず、御団体の活動内容について教えていただけますか？
**（アイスブレイク／前提理解）**

**質問文:**
> 「本日はお時間いただきありがとうございます。最初に、御団体がどのようなボランティア活動をされているか、概要を教えていただけますか？」

**深掘り用サブ質問:**
- 「活動はどのくらいの頻度で行っていますか？ 1回あたり何名くらいが参加されますか？」
- 「参加されるボランティアの方は、どんな年齢層・属性の方が多いですか？（学生、社会人、シニア等）」
- 「ボランティアの方には、具体的にどのような作業や役割をお願いしていますか？」

### Q2. 現在、ボランティアの募集はどのような方法で行っていますか？
**（現状の募集チャネルの把握）**

**質問文:**
> 「ボランティアを集めたいとき、普段どのような方法で募集をかけていますか？ 使っている媒体やサービスがあれば教えてください。」

**深掘り用サブ質問:**
- 「それぞれの媒体で、実際にどのくらい応募が来ますか？ 効果を感じている媒体はどれですか？」
- 「その媒体を選んだ理由は何ですか？ コスト面や手間なども含めて教えてください。」
- 「過去に使ってみたけどやめた媒体やサービスはありますか？ やめた理由も教えていただけますか？」
- 「口コミや紹介で来る方はどのくらいの割合ですか？」

### Q4. ボランティアの方が"1回きり"で終わってしまうことはありますか？ 継続参加してもらうために工夫されていることはありますか？

**質問文:**

**深掘り用サブ質問:**
- 「リピートしてくれる方と、1回で終わる方の違いは、何だと感じていますか？」
- 「辞めてしまう方から理由を聞いたことはありますか？ どんな理由が多いですか？」
- 「"最初から合わなかった"ケースと、"途中で合わなくなった"ケースではどちらが多いですか？」
- 「リピーターの方は、全体の何割くらいですか？」

**深掘り用サブ質問:**
- 「合っていた方は、具体的にどんな性格や姿勢の方でしたか？」
- 「合わなかったケースでは、どんなところにギャップを感じましたか？」

- 「応募から参加決定まで、だいたいどのくらいの日数がかかりますか？」

### 【中盤：チャネル・ツール検証】（Q8〜Q10）コミュニケーション手段やデジタル活用の実態を探る

### Q8. 参加が決まったボランティアの方との普段の連絡は、どのツールでやり取りしていますか？
**（LINE連携機能の需要検証）**

**質問文:**
> 「活動に参加が決まったボランティアの方との日常的な連絡は、何を使ってやり取りされていますか？ メール、LINE、電話など、メインで使っているものを教えてください。」

**深掘り用サブ質問:**
- 「LINEは使われていますか？ 使っている場合、公式LINEアカウントですか、それとも担当者の個人LINEですか？」
- 「LINEを使っていない場合、使わない理由はありますか？ 今後導入する予定はありますか？」
- 「連絡ツールに関して不便を感じることはありますか？（返信が来ない、情報が散らばる等）」
- 「参加者から"この連絡手段がいい"と希望を言われることはありますか？」

> **メモ欄:**
>
>

- 「もし参加者がシェアしたくなるような"映える"コンテンツ（診断結果のキャラクター画像など）が提供されたら、拡散に役立ちそうですか？」

### Q11. 御団体の活動がうまくいっているかどうかを、どのように判断されていますか？
**（分析・レポート機能の需要検証）**

**質問文:**

**深掘り用サブ質問:**
- 「参加人数、リピート率、満足度など、定期的にチェックしている数字はありますか？」

- 「"データで見える化されたら助かる"と思う情報はありますか？」
- 「助成金や寄付者への報告資料に、ボランティアに関するデータを使うことはありますか？」

### Q12. もし「応募者の性格タイプや価値観が事前にわかる仕組み」があったら、活用したいと思いますか？
**（プロダクトコンセプトへの反応確認）**

**質問文:**
> 「仮に、ボランティアに応募してくれた方の性格タイプや価値観が、応募の時点でわかる仕組みがあったとしたら、どう思いますか？ 率直なご感想を聞かせてください。」

**深掘り用サブ質問:**
- 「そういった情報があれば、受け入れの判断やチーム編成に活かせそうですか？」
- 「もし活かすとしたら、どんな性格の情報が一番知りたいですか？（例：協調性が高い、リーダーシップがある、コツコツ型 等）」
- 「逆に、性格で判断することに抵抗感や懸念はありますか？」
- 「参加者側が自分の性格タイプを知ってから応募できるのは、良いことだと思いますか？」

> **メモ欄:**
>
>

### Q13. ボランティアの募集・管理をサポートするサービスがあるとしたら、どんな機能があると嬉しいですか？
**（潜在ニーズ・要望の発掘）**

**質問文:**
> 「もしボランティアの募集や管理を手助けしてくれるWebサービスがあるとして、"これがあったら助かる"という機能を自由に挙げていただけますか？ 実現可能かどうかは気にしなくて大丈夫です。」

**深掘り用サブ質問:**
- 「今使っている募集サービスやツールで、"ここが不便だな"と感じるところはありますか？」
- 「参加者の管理（出欠、連絡先、活動履歴など）は、今どのように行っていますか？ 困っている点はありますか？」
- 「もし理想のサービスがあるとしたら、毎日・毎週使いたいものですか？ それとも募集のときだけ使えればいいですか？」
- 「他の団体さんが使っていて"良さそうだな"と思ったツールやサービスはありますか？」

> **メモ欄:**
>
>

### Q14. 他のNPO法人や団体との横のつながりはありますか？ ボランティア募集に関して情報交換はされていますか？

- 「ネットワークや協議会（ボランティアセンター等）に所属されていますか？ そこでの情報共有は役に立っていますか？」
- 「"この団体さんにもこのサービスの話を聞いてほしい"と思う団体はありますか？」

### Q15. こういったサービスが有料だった場合、御団体として利用を検討されますか？
**（マネタイズ仮説の検証）**

**質問文:**
