# 未ログインLP Balanced Pop 配色デザイン

## 目的

現在のモバイルファーストLPの構成、写真、コピー、導線を維持しながら、ミヤマクリエイティブを想起させる遊び心のある色面を加える。ボランティーらしい親しみやすさと信頼感を損なわず、スクロール中にセクションの切り替わりを楽しく感じられる状態を目指す。

## 選択した方向性

比較した3案のうち「A. Balanced Pop」を採用する。

- オレンジをブランドと主要CTAの主役として維持する
- ティール、黄色、紫を補助色として追加する
- 強い原色を全面に敷かず、淡い色面と小さなアクセントへ展開する
- 写真、ウォームホワイト、余白の上品さを残す
- グラデーション、CSSで描く装飾、絵文字は追加しない

## カラートークン

既存のセマンティックカラーは変更せず、LP専用のPOPカラーを追加する。

| 用途 | トークン | 値 |
| --- | --- | --- |
| ブランドオレンジ | `--primary` | 既存の `#fb5b01` を維持 |
| ティール | `--pop-teal` | `#12a4a1` |
| ティール淡色 | `--pop-teal-soft` | `#dff5f1` |
| イエロー | `--pop-yellow` | `#f6c644` |
| イエロー淡色 | `--pop-yellow-soft` | `#fff3c9` |
| パープル | `--pop-purple` | `#9370db` |
| パープル淡色 | `--pop-purple-soft` | `#eee7ff` |
| コーラル淡色 | `--pop-coral-soft` | `#ffe4d5` |
| LP背景 | `--lp-cream` | `#fff8ee` |

濃色はアイコン、短いラベル、枠線、句読点へ限定する。本文や長い見出しは既存の `--text-dark` と `--text-body` を使い、色付き文字を長文へ適用しない。

## セクション別の適用

### ヘッダーとヒーロー

- ヘッダーはウォームホワイトを維持する
- ヒーロー背景を淡いクリームにする
- 見出し本文は黒のまま、句読点をオレンジ、ティール、紫で分散する
- 性格傾向ラベルへティールの薄い面を追加する
- 主要CTAはオレンジ、補助CTAはオレンジ枠を維持する
- 既存の透明軌道モチーフを装飾として使い、追加のCSS図形は作らない

### 活動スタイル

- セクション全体へイエローの淡色面を使用する
- 4つの代表カードへコーラル、ティール、イエロー、パープルを割り当てる
- 写真はそのまま使用し、カード下部のラベル、枠線、リンク色だけを変える
- 横スクロールとカード寸法は変更しない

### 課題解決

- セクション背景はウォームホワイトを維持する
- 問題側をコーラル淡色、解決側をティール淡色に統一する
- 問題から解決への意味が色だけに依存しないよう、既存のアイコンと文章を残す

### 使い方・診断プレビュー

- セクション面をティール淡色へ変更する
- ステップ番号はオレンジ、ティール、パープルを順番に使う
- BIG FIVEプレビューは5特性ごとに複数の淡色面を使う
- 活動スタイル結果カードは濃いティールを基調とし、白文字のコントラストを確保する

### 10の活動スタイル

- セクション背景はクリームを維持する
- 既存のタイプ別色をPOPトークンへ寄せ、カードの上辺またはアイコン面で色を見せる
- 10枚すべてを強い色面にせず、白いカードと淡色アクセントを維持する

### 参加メリット

- セクション全体へパープル淡色を薄く使用する
- 番号バッジとカード下部へオレンジ、ティール、イエローを割り当てる
- 写真の視認性を優先し、画像上に強いカラーオーバーレイを置かない

### 利用イメージと主な機能

- 利用イメージはティール淡色を基本面とし、カードごとにコーラル、イエロー、パープルのラベルを付ける
- 主な機能は4カードへ補助色を1色ずつ割り当てる
- アイコンは既存ライブラリを使用し、新しい図形アセットは作らない

### FAQ、ボトムCTA、フッター

- FAQはクリーム背景と白カードを維持し、質問番号を補助色でローテーションする
- ボトムCTAはブランドオレンジを維持し、透明軌道モチーフでティールと黄色を加える
- フッターはウォームホワイトを維持し、リンクのホバー色へティールを加える

## コンポーネント方針

- LP専用カラーは `globals.css` のトークンとして定義する
- セクション固有の色選択は各LPコンポーネント内の静的設定に置く
- レイアウト、コンポーネント境界、認証分岐、ルート構成は変更しない
- 配色は各セクションの静的設定に閉じ、今回のための新しい共有モジュールは追加しない
- クライアントコンポーネントを増やさない

## アクセシビリティ

- 本文色は既存の濃色を維持する
- 白文字を使う面は十分なコントラストを持つ濃色に限定する
- 選択状態、問題・解決、FAQ開閉は色だけで表現しない
- フォーカスリングとリンクのホバー状態を維持する
- 新しいアニメーションは追加せず、既存のReveal動作を変更しない

## 変更しないもの

- ページ構成とセクション順
- 生成済みの写真とブランドアセット
- 日本語コピーと「ボランティー」表記
- 診断、活動一覧、ログイン、会員登録へのリンク先
- 認証後ホーム
- FAQとモバイルメニューの動作

## 検証

- 既存LP単体テストを実行する
- セマンティクスや操作動作を変更しないため、既存テストを回帰確認として使用する
- `npm test`、`npm run lint`、`npm run build` を実行する
- 390 × 844でヒーロー、活動スタイル、使い方、メリット、FAQを撮影する
- 横方向のオーバーフロー、画像読み込み、メニュー、FAQ開閉、CTAリンクを確認する
- 更新前のA案モックと更新後スクリーンショットを同一画像内で比較し、`design-qa.md` を更新する

## 完了条件

- オレンジ、ティール、黄色、紫がLP全体へ一貫して現れる
- POPになっても写真と日本語本文の可読性が落ちていない
- 構成、コピー、導線、認証分岐に回帰がない
- 390px幅で横スクロールが発生しない
- Design QAが `final result: passed` になる
