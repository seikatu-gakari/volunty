# Admin E2E Expansion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Playwright E2E coverage for Issue #168 A-E1〜A-E6 and the seed/persona support that keeps those tests independent and repeatable.

**Architecture:** Keep product behavior unchanged. Add deterministic E2E personas and fixtures in `seed:e2e`, expose existing cards through accessible role/label attributes, and split E2E specs by admin user management versus organization review. Mutation tests use `admin-review`; the existing `admin` persona remains read-only.

**Tech Stack:** Next.js App Router, TypeScript, Prisma, Supabase Auth test route, Vitest, Playwright.

## Global Constraints

- UIテキスト、コードコメント、説明は日本語で統一する。
- TypeScript では型安全性を優先し、`any` を追加しない。
- 破壊的変更は行わない。
- 既存の `.codex/config.toml` 変更には触れない。
- `participant-suspendable` は `user-suspendable` に改名する。
- `admin` は読み取り専用、`admin-review` は管理者 mutation 用として使う。
- A-E1〜A-E6 は Playwright の test 名で追跡可能にする。
- 承認・否認・凍結の mutation 対象は専用 fixture に分離する。
- `seed:e2e` は審査状態、審査履歴、凍結状態を毎回初期状態へ戻す。
- seed 追加/リセットロジックには Vitest の単体テストを追加する。
- E2E では固定 wait と CSS class selector を追加しない。既存の CSS class selector も今回触る範囲では置き換える。
- Scope out: OAuth/mail 実サービス、production/preview への破壊的テスト、Issue #166/#167、新しいプロダクト機能。
