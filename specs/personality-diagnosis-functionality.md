# 性格診断機能 機能・実装ドキュメント

## 1. 概要
ボランティア参加者の性格特性をBIG5理論に基づいて診断し、最適なボランティア活動や人物タイプを提案する機能です。全50問の質問に回答することで、個人の特性を可視化します。

## 2. 機能一覧

### 2.1 診断ウィザード
- **質問回答**: 1ページに1問ずつ表示され、5段階のリッカート尺度（全く当てはまらない 〜 非常に当てはまる）で回答します。
- **進捗表示**: 現在の回答数と全体の進捗率（%）をプログレスバーで表示します。
- **ナビゲーション**: 「戻る」ボタンで前の質問に戻り、回答を修正可能です。
- **デバッグ機能**: 開発環境（`NODE_ENV=development`）では、残りの質問をランダムに回答して即座に結果を確認できるデバッグボタンが表示されます。

### 2.2 診断結果表示
- **人物タイプ判定**: BIG5スコアに基づき、10種類の人物タイプから最も適合するものを表示します。
    - **完全一致**: すべての基準を満たすタイプがある場合。
    - **近似一致**: 完全一致がない場合、ユークリッド距離が最も近いタイプを表示します。
- **詳細情報**:
    - タイプの説明
    - ボランティア活動における強み
    - 適した活動の提案
- **スコアチャート**: BIG5の各特性（外向性、協調性、誠実性、神経症傾向、開放性）のスコア（0-100）をバーチャートで可視化します。

## 3. 技術仕様と実装詳細

### 3.1 アーキテクチャ概要
本機能は Next.js (App Router) 上で動作し、状態管理に **XState** を採用しています。これにより、診断フロー（回答中、計算中、完了など）を堅牢に管理しています。

### 3.2 ファイル構成
- `app/src/app/diagnosis/`: UIコンポーネント
    - `page.tsx`: エントリーポイント。`DiagnosisWizard` をラップします。
    - `components/DiagnosisWizard.tsx`: 診断フロー制御の要。XStateマシンをフックし、状態に応じてサブコンポーネントを切り替えます。
    - `components/QuestionCard.tsx`: 質問表示コンポーネント。進捗バーと選択肢ボタンを持ちます。
    - `components/ResultView.tsx`: 結果表示コンポーネント。スコアの可視化とタイプ情報の表示を行います。
- `app/src/lib/personality/`: コアロジック
    - `types.ts`: `BIG5Trait`, `Question`, `PersonalityProfile` などの型定義。
    - `constants.ts`: 50問の質問データ (`BIG5_QUESTIONS`) と10種類の人物タイプ定義 (`PERSONALITY_TYPES`)。
    - `logic.ts`: 純粋関数としてのスコア計算・判定ロジック。
    - `machine.ts`: 診断フローの状態遷移定義。

### 3.3 詳細ロジック解説

#### A. スコア計算アルゴリズム (`logic.ts`)
BIG5の各特性（外向性、協調性、誠実性、神経症傾向、開放性）について、以下の手順でスコア（0-100）を算出します。

1.  **回答の集計**:
    各特性につき10問の質問があります。回答は1〜5の数値で記録されます。
2.  **逆転項目の処理**:
    質問には「逆転項目（reversed）」が設定されています（例：「話すのが苦手だ」は外向性の逆転項目）。
    逆転項目の場合、スコアは `6 - 回答値` として計算します（5なら1点、1なら5点）。
3.  **平均値の算出**:
    特性ごとに10問の合計スコアを計算し、平均値（1.0〜5.0）を求めます。
4.  **正規化**:
    平均値を0〜100のスケールに変換します。
    $$ Score = \frac{Average - 1}{4} \times 100 $$

#### B. 人物タイプ判定ロジック (`logic.ts`)
算出された5つのスコアをもとに、最適な人物タイプを決定します。

1.  **完全一致判定 (`determinePersonalityType`)**:
    各人物タイプには基準（Criteria）が定義されています（例：外向性 $\ge$ 75, 開放性 $\ge$ 80）。
    ユーザーのスコアが、あるタイプの全ての基準を満たす場合、そのタイプを「完全一致」とします。
    複数のタイプに一致した場合は、`priority`（優先度）が高いものを採用します。

2.  **近似一致判定 (`findClosestPersonalityType`)**:
    完全一致するタイプがない場合、**ユークリッド距離**を用いて最も近いタイプを探します。
    - 各タイプの基準から「理想スコア」を定義（最小値+10、最大値-10、または範囲の中央値）。
    - ユーザーのスコアベクトルと、各タイプの理想スコアベクトルとの距離を計算。
    - 距離が最小のタイプを「最も近いタイプ」として提示します。

#### C. 状態管理 (`machine.ts`)
XStateを用いて以下のステートマシンを構築しています。

- **States**:
    - `idle`: 初期状態。開始ボタン待ち。
    - `answering`: 回答中。`ANSWER` イベントで回答を保存し、次の質問へ。`BACK` で戻る。
    - `checkProgress`: 進捗確認。全問回答済みなら `calculating` へ、未完了なら `answering` へ。
    - `calculating`: 計算中。非同期で `calculateBIG5Result` を実行。
    - `completed`: 完了。結果を表示。`RESET` で `idle` に戻る。
    - `error`: エラー状態。

### 3.4 データ構造例

#### 質問データ (`Question`)
```typescript
{
  id: 'e1',
  text: '初対面の人とも気軽に話しかけることができる',
  trait: 'extraversion',
  reversed: false,
  options: [{ label: '全く当てはまらない', value: 1 }, ...]
}
```

#### 人物タイプ定義 (`PersonalityType`)
```typescript
{
  id: 'innovator-leader',
  name: 'イノベーター・リーダータイプ',
  criteria: {
    extraversion: { min: 75 },
    openness: { min: 80 },
    conscientiousness: { min: 70 }
  },
  // ...
}
```

## 4. 使用方法

### 4.1 起動
```bash
cd app
npm run dev
```
ブラウザで `http://localhost:3000/diagnosis` にアクセスしてください。

### 4.2 検証スクリプト
ロジックの正当性を検証するためのスクリプトが含まれています。
```bash
npx tsx scripts/verify-diagnosis.ts
```
