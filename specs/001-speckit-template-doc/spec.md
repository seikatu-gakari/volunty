# フィーチャー仕様: Speckit を用いた仕様駆動開発ワークフローのドキュメント化

## 概要
- **ゴール**: GitHub Copilot を主要エージェントとして利用する Speckit ベースの仕様駆動開発ワークフローの実行手順を `README.md` にまとめる。
- **対象読者**: Speckit ツール群を使ってフィーチャー仕様を作成・運用する必要があるリポジトリのコントリビューター。
- **動機**: コマンドリファレンスを簡潔かつ網羅的に提示し、プロンプトを逐一参照しなくても Speckit スクリプトの実行と Copilot 連携方法を理解できるようにする。

## 要件
1. Speckit コマンドを実行するための前提条件（ブランチ命名規則、スクリプト配置場所、利用環境）を明示すること。
2. 計画テンプレート作成、エージェントコンテキスト更新、タスク生成、成果物の同期といった主要コマンドを解説すること。
3. ワークフロー内での GitHub Copilot の活用方法（エージェントコンテキスト更新や指示ファイル）を強調すること。
4. フィーチャー計画（plan/research）から設計（data-model/contracts）を経てタスク生成に至るライフサイクルを説明すること。
5. このリポジトリで発生しやすい Speckit スクリプトのエラーに対するトラブルシューティングを含めること。

## 非ゴール
- Speckit の実行を自動化したり新しいスクリプトを追加すること。
- ブランチ要件以上の Git 基礎を教えること。
- Speckit 以外のツール（CI やデプロイなど）を説明すること。

## 受け入れ条件
- `README.md` に仕様駆動ワークフロー向けの専用セクションが追加されている。
- セクション内に各フェーズを網羅するコマンド例と解説が含まれている。
- README から `.specify/scripts/bash/` 内のスクリプトと `.github/copilot-instructions.md` への言及が行われている。
- README に従うだけでコントリビューターが Speckit による計画〜タスク生成を完結できる。
